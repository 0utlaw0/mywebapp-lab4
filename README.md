# Лабораторна робота №4: IaC. Terraform. Ansible (Варіант 6)

## Опис індивідуального завдання (Варіант N = 6)
- **V2 = (6 % 2) + 1 = 1**: СУБД **MariaDB** (порт `3306`), передача параметрів підключення до БД через аргументи командного рядка.
- **V3 = (6 % 3) + 1 = 1**: Веб-застосунок **Notes Service** (`mywebapp`).
- **V5 = (6 % 5) + 1 = 2**: Внутрішній порт застосунку **5200** (`127.0.0.1:5200`).

## Архітектура системи та безпека
- **Мережа (`lab4_net`)**: Ізольована NAT-мережа `192.168.133.0/24` у гіпервізорі KVM/QEMU (`libvirt`).
- **VM1 (`lab4-worker`)**:
  - **Nginx** слухає порт `80` (`0.0.0.0:80`) та проксіює вхідні HTTP-запити на `127.0.0.1:5200`.
  - **Web-застосунок (`mywebapp`)** працює як `systemd`-сервіс від непривілейованого системного користувача `app` (без `sudo` та інтерактивного шелу).
- **VM2 (`lab4-db`)**:
  - **MariaDB** слухає порт `3306`; фаєрвол **UFW** дозволяє вхідні з'єднання на порт `3306` виключно з IP-адреси `lab4-worker`.
- **Керування доступом (SSH та Sudo)**:
  - Автентифікація по паролю по SSH вимкнена (доступ лише за SSH-ключем).
  - `teacher` — повні права `sudo` без пароля (`NOPASSWD: ALL`).
  - `operator` — обмежені права `sudo` для перегляду логів і перезапуску сервісу застосунку.
